# Mosaic Disco Urn
A tool for exploring possible solutions to the Qwantzle.

Mostly written by LLMs, unfortunately, as I was lazy and am not very familiar with building GUIs.

You can run it in your browser at https://paulstansifer.github.io/mosaic-disco-urn/

To run locally:
```
nvm install 20  # if necessary
nvm use 20  # if necessary
npm run dev
```
